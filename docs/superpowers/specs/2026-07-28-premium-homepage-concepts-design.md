# 찬지기 프리미엄 홈페이지 A/B/C 비교 시안 설계

## 1. 목표

기존 찬지기 홈페이지를 보존하면서 프리미엄 브랜드 인지도를 강화하는 세 가지
디자인 방향을 동일한 콘텐츠 조건으로 비교한다. 비교 결과를 바탕으로 한 방향을
선택하며, 선택 전에는 어느 시안도 운영 루트를 대체하지 않는다.

## 2. 작업 범위

비교 시안은 다음 경로에 독립적인 정적 페이지로 작성한다.

```text
concepts/
├── a-editorial/
│   ├── index.html
│   ├── styles.css
│   └── app.js
├── b-cinematic/
│   ├── index.html
│   ├── styles.css
│   └── app.js
└── c-gallery/
    ├── index.html
    ├── styles.css
    └── app.js
```

운영 중인 루트 `index.html`과 `assets/`는 수정하지 않는다. 시안은 기존 에셋을
상대 경로로 참조하며, 비교에 필요한 신규 그래픽이 생기면 각 시안 폴더 안에만 둔다.

## 3. 공통 비교 조건

세 시안은 시각 스타일만 달라지고 비교 기준은 같아야 한다.

- 1순위 목적: 프리미엄 브랜드 인지도
- 기본 언어: 한국어
- 공통 이야기: 원물 → 시간과 제조 → 식탁
- 공통 핵심 문장: “재료에서, 마지막 한 술까지.”
- 공통 핵심 섹션:
  1. Hero
  2. 브랜드 철학
  3. 원물과 제조
  4. 식탁과 완성
- 기존 사진과 영상을 우선 사용한다.
- 각 시안에 해당 방향을 대표하는 인터랙션을 1~2개만 적용한다.
- 비교 단계에서는 주문, 회원가입, 결제, CMS, 분석 도구를 추가하지 않는다.
- 5개 국어와 전체 제품 카탈로그는 최종 방향 선택 후 확장한다.

## 4. 시안 A — 한국적 식문화 에디토리얼

### 의도

찬지기를 “예쁜 소스 브랜드”가 아니라 재료와 시간에 대한 태도를 가진 한국 식문화
브랜드로 인식시킨다.

### 시각 언어

- 따뜻한 한지색 바탕, 먹색 본문, 발효 고추색과 올리브색 포인트
- 큰 한글 제목과 절제된 영문·한자 보조 표기
- 비대칭 에디토리얼 그리드와 넓은 여백
- 원재료의 질감과 손의 흔적이 보이는 이미지 크롭
- 장식적 전통 문양 대신 여백, 선, 종이 질감으로 한국성을 표현

### 구조와 인터랙션

- Hero: 큰 문장과 원물 이미지의 비대칭 2열 구성
- 브랜드 철학: 짧은 선언문과 세로 장 번호
- 원물과 제조: 이미지·텍스트가 교차하는 에디토리얼 챕터
- 식탁: 완성 요리를 넓은 이미지로 마무리
- 인터랙션: 스크롤 진입 시 절제된 문장·이미지 reveal, 현재 챕터 표시

### 기대 효과와 위험

- 세 안 중 브랜드 고유성과 장기 확장성이 가장 높다.
- 현재 사이트와 가장 명확하게 구분된다.
- 여백과 타이포 비중이 커서 카피와 이미지 크롭의 완성도가 중요하다.

## 5. 시안 B — 시네마틱 여정

### 의도

기존 사이트의 영상 자산과 몰입감을 발전시켜, 한 술이 완성되는 과정을 감성적으로
기억하게 한다.

### 시각 언어

- 짙은 먹색과 갈색 배경, 빛이 닿은 식재료 색상
- 풀블리드 영상과 강한 명암 대비
- 화면당 하나의 핵심 문장
- 장면 번호와 진행 상태를 명확하게 표시

### 구조와 인터랙션

- Hero: 풀스크린 영상과 브랜드 문장
- 브랜드 철학: 영상 위 짧은 선언
- 원물과 제조: 스크롤에 따라 장면과 카피가 순차 전환
- 식탁: 밝아지는 마지막 장면으로 여정을 종료
- 인터랙션: sticky 장면 전환, 미디어와 카피의 동기화
- 모바일·저감 모션 환경에서는 정적 이미지와 단순 페이드로 대체

### 기대 효과와 위험

- 감성적 첫인상과 기존 영상 활용도가 가장 높다.
- 현재 사이트와 구조적 유사성이 남을 수 있다.
- 영상 용량, 모바일 발열, 스크롤 제어를 보수적으로 관리해야 한다.

## 6. 시안 C — 현대적 푸드 갤러리

### 의도

소스, 재료, 요리를 편집숍의 컬렉션처럼 보여주어 현대적인 프리미엄 식품 브랜드로
인식시킨다.

### 시각 언어

- 크림색과 밝은 회색 바탕, 선명한 식재료 색상
- 이미지 우선 모듈형 그리드
- 짧은 캡션, 제품명, 재료명 중심의 정보 위계
- 균일하지 않은 카드 크기로 편집적 리듬 형성

### 구조와 인터랙션

- Hero: 대표 제품·요리 이미지와 짧은 브랜드 문장
- 브랜드 철학: 핵심 가치 카드
- 원물과 제조: 사진 갤러리와 간결한 캡션
- 식탁: 요리별 이미지 모자이크
- 인터랙션: 카드 hover·focus 확대, 이미지와 캡션의 부드러운 reveal

### 기대 효과와 위험

- 모바일 안정성과 제품 확장성이 가장 높다.
- 제품·레시피·콘텐츠 허브로 발전시키기 쉽다.
- 강한 패키지 사진이 부족하면 일반적인 라이프스타일 브랜드처럼 보일 수 있다.

## 7. 기술 설계

- 빌드 도구 없이 GitHub Pages에서 직접 실행되는 HTML, CSS, JavaScript를 사용한다.
- 세 시안은 서로의 CSS와 JavaScript를 공유하지 않는다. 한 시안의 수정이 다른 시안의
  비교 결과에 영향을 주지 않게 하기 위함이다.
- 기존 에셋은 `../../assets/...` 상대 경로로 읽는다.
- JavaScript 없이도 핵심 콘텐츠를 읽을 수 있게 HTML에 본문을 둔다.
- JavaScript는 reveal, 장면 상태, 모션 축소 같은 표현 계층에만 사용한다.
- 외부 애니메이션 라이브러리는 시안 B에서 기본 CSS·Web API로 목표를 달성할 수 없을
  때만 추가한다.
- 브라우저 저장소, 외부 API, 폼 제출, 사용자 데이터 전송은 사용하지 않는다.

## 8. 반응형·접근성

- 기준 화면: 데스크톱 1440×900, 모바일 390×844
- 레이아웃은 콘텐츠가 잘리지 않고 세로 스크롤로 완결되어야 한다.
- 모든 링크와 버튼은 키보드로 접근 가능해야 한다.
- 이미지에 목적에 맞는 대체 텍스트를 제공한다.
- 텍스트와 배경은 읽을 수 있는 대비를 유지한다.
- `prefers-reduced-motion: reduce`에서는 자동 재생과 큰 이동을 제거한다.
- 시안 B의 영상에는 poster를 지정하고, 영상 실패 시에도 카피를 읽을 수 있어야 한다.

## 9. 비교 산출물

각 시안에서 다음 화면을 채팅에 이미지로 제공한다.

- 데스크톱 Hero
- 데스크톱 핵심 중간 섹션
- 모바일 Hero

최종 비교표에는 다음 항목을 포함한다.

- 프리미엄 인상
- 한국적 고유성
- 기존 에셋 활용도
- 콘텐츠 확장성
- 모바일·성능 안정성
- 구현·운영 복잡도

## 10. 검증 기준

- 세 경로가 로컬 정적 서버에서 정상적으로 열린다.
- 콘솔 오류와 깨진 로컬 에셋이 없다.
- 데스크톱과 모바일 기준 화면에서 가로 넘침이 없다.
- 키보드 탐색과 저감 모션 모드가 동작한다.
- 세 시안에 동일한 핵심 이야기와 섹션이 포함된다.
- 루트 `index.html`의 Git 객체 해시가 작업 전후 동일하다.
- 기존 `assets/` 아래 tracked 파일의 변경 목록이 비어 있다.
- 비교 스크린샷은 같은 화면 크기에서 촬영한다.

## 11. 완료 조건

세 비교 시안과 검증 결과, 채팅용 비교 이미지가 준비되고 사용자가 최종 방향을
선택할 수 있으면 이번 비교 단계가 완료된다. 선택한 시안의 운영 전환, 다국어 확장,
추가 촬영과 제품 카탈로그는 별도 단계로 다룬다.
